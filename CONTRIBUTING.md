# Contributing

Thanks for your interest in tapo-desktop.

## Project layout

- **`crates/tapo-core`**: the protocol library (login/MFA, camera list, cloud relay, TS demux,
  device commands, talk muxer, alerts). GUI-free and platform-agnostic. Put protocol/parsing logic
  here, with unit tests.
- **`crates/tapo-desktop`**: the egui app (UI, decode, GPU render, audio I/O, worker thread).
  Keep decoding/platform concerns here, not in the core.

Keep the core decoupled from the UI: `tapo-core` must not depend on egui, a decoder, or a GUI.

## Prerequisites

- A Rust toolchain (stable) with a C compiler (openh264 builds from source).
- Linux also needs: `libasound2-dev libxkbcommon-dev libwayland-dev libxcb1-dev`.
- No ffmpeg needed.

## Build, test, format

```sh
cargo build
cargo test            # core has unit tests (signing, TS demux, muxer round-trip, G.711, ...)
cargo fmt --all
cargo clippy --workspace
```

CI runs `fmt --check`, tests and a release build on Linux, macOS and Windows, and must be green.

## Pull requests

- Branch from `main`; keep PRs focused and commits small and descriptive.
- Add a test for new non-trivial logic in `tapo-core` (parsers, codecs, protocol framing).
- Run `cargo fmt` and `cargo clippy` before pushing.
- Don't commit secrets or captures: `session.json`, `*.flow`, `*.ts` and `/dist` are gitignored.
  Never paste your TP-Link token or camera footage into issues/PRs.

## Reporting bugs

In the app, open **Log → Open log file** and attach it. Say which camera model (C200/C210/C310/…),
your OS, and the steps. The log already masks tokens.

## Protocol notes

This client targets the TP-Link cloud. It is
cameras. It is unofficial and may change. When adding an endpoint or command, prefer values
verified against a camera, and keep error codes surfaced with the failing method name so issues
stay diagnosable.

## Releases

Packaging runs in GitHub Actions on a `v*` tag (`.github/workflows/release.yml`), producing a macOS
`.dmg`, a Linux `.tar.gz` and a Windows `.zip`. Icons are generated by `packaging/gen_icons.py`.
